# WinPhoneBook

دفترچه تلفن حرفه‌ای فارسی برای Windows 7 SP1 و بالاتر.

## امکانات
- مخاطب با اطلاعات کامل، چند شماره و ایمیل
- گروه، برچسب، علاقه‌مندی و جستجوی سریع
- سطل زباله و بازیابی
- یادآوری
- تشخیص مخاطبین احتمالی تکراری
- Backup/Restore رمزنگاری‌شده
- Import/Export CSV
- رابط فارسی و RTL
- ذخیره‌سازی آفلاین

## امنیت
داده‌ها با AES-256 و HMAC-SHA256 و PBKDF2 محافظت می‌شوند.

## Build
.NET Framework 4.7.2، مناسب Windows 7 SP1/8/10/11. Build رسمی با GitHub Actions روی Windows انجام می‌شود.
